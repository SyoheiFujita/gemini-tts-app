# Gemini TTS 音声生成

最大3000文字のテキストを Gemini 3.8 Flash TTS で音声にし、MP3 にして Google ドライブのフォルダへ保存するスマホ向けWebアプリです。

アプリ: https://syoheifujita.github.io/gemini-tts-app/

## ドライブ保存の設定

保存には、自分の Google アカウントで動く Apps Script を1つ用意します（最初の1回だけ）。

1. PC で https://script.google.com を開き、「新しいプロジェクト」を作る
2. 最初からあるコードを全部消して、[`gas/Code.gs`](gas/Code.gs) の中身を貼り付ける
3. `TOKEN` の `'ここを合言葉に変更'` を、自分だけが知っている合言葉に書き換えて保存する
4. 右上の「デプロイ」→「新しいデプロイ」→ 歯車から「ウェブアプリ」を選び、次のように設定して「デプロイ」
   - 次のユーザーとして実行: **自分**
   - アクセスできるユーザー: **全員**
5. 権限の確認画面が出たら許可する（「このアプリは Google で確認されていません」と出たら「詳細」→「（プロジェクト名）に移動」）
6. 表示された「ウェブアプリの URL」（`https://script.google.com/macros/s/.../exec`）をコピーする
7. スマホでアプリを開き、「保存用スクリプトのURL」と「合言葉」を入力する

「アクセスできるユーザー: 全員」はスマホのページからログインなしで送れるようにするためです。合言葉が合わない送信は保存されません。URL と合言葉は人に教えないでください。

`Code.gs` を書き換えたときは、「デプロイ」→「デプロイを管理」→ 鉛筆アイコン →「バージョン: 新バージョン」で更新すると、URL はそのまま使えます。

## 保存されるファイル

- 形式: MP3（モノラル 96kbps）
- 名前: `tts_日付-時刻_本文の先頭15文字.mp3`
- ドライブ上のファイルの「説明」に読み上げた本文が入ります
- 生成した音声はページには残りません。保存に失敗したときだけ、再送できるよう一時的に画面のメモリ内に保持します
